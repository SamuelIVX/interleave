# Test-quality audit

> Inventory baseline: `adb52ee`, 514 test methods in 47 classes, expanded by JUnit into 526 invocations. Dispositions refer to methods, not invocations. A passing test or a `keep` decision does not prove its whole class correct.

## Decisions

| Disposition | Baseline methods |
|---|---:|
| keep | 433 |
| strengthen | 65 |
| consolidate | 16 |

Each row names the protected contract through its method and concrete check. The plausible defect is a missing or changed named output, transition, rejection, copy, or callback. The oracle column identifies shared implementation and acceptance-only limitations. Excerpts are locators, not replacements for the complete source fixture. New clock tests and supplied-store checks are additions, so are outside the baseline denominator.

## Independent checks retained

- `CanonicalEncoderContractTest` samples values through an independent value-keyed store; it does not filter samples with the encoder under test.
- `StateEncodingFidelityTest` checks field changes and encoding boundaries, and `HashingStateStoreLifecycleTest` exercises real hash collisions, fresh copies, clearing and minimum costs.
- `PropertyAwarePorTest` checks 1,875 generated program/property combinations with replay.
- CBS differential, monotonicity, trace emission and store contracts have distinct input sets and obligations. Shared core execution makes differential agreement useful but insufficient alone.
- Exception and valid-input acceptance tests are meaningful at an input boundary. A small assertion count is not a reason to delete them.

## Limits and separate findings

- DSL conjunction tests previously claimed short-circuit evaluation while both a false conjunct and an evaluation error become a violation. The name now states that observable outcome. Evaluation order itself is deferred; no assertion claims to protect it.
- Default PIT measures `state.*` and `cb.*`, not the whole engine. Expanded mutation results retain survivors; the cleanup does not claim universal mutation coverage. See the accompanying spec for measured counts and falsification.
- **Separate production defect:** `ReportWriter.writeJson` interpolates free-form names/strategy/verdict without JSON escaping, and `TraceRecord.toJson` interpolates `programHash`. Quotes or backslashes can emit malformed JSON. No production fix or weakened assertion is included here. The committed tests check valid ordinary fixtures; arbitrary-string serialization requires its own regression and fix.
- Timing remains wall-clock based with millisecond truncation. The package-private per-call clock is a test seam, not a new public timing contract.
